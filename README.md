# SQL-Summative-Lab-# SQL Summative Lab

## 📌 Project Overview
This project analyzes customer and product data using SQL queries to generate insights and support business decisions.

## 🎯 Objectives
- Perform SQL queries (SELECT, JOIN, GROUP BY, HAVING)
- Analyze customer and sales data
- Visualize key insights using Python

## 🛠️ Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- SQLite
- Jupyter Notebook

## 📊 Key Insights
- High credit limit customers identified in California
- International customers with "Collect" identified for campaigns
- Average credit limits vary significantly by state

## 📈 Visualizations
- Bar chart showing average credit limit per state
